# Информационная система автосервиса

Учебный проект по дисциплине «Проектный менеджмент».

**Команда:** Роде, Солопанов, Пухов.

ИС предназначена для небольшого автосервиса: клиенты и автомобили, запись на обслуживание, заказы-наряды, назначение механиков, услуги и запчасти, статусы ремонта, итоговая стоимость и выдача автомобиля.

## Воспроизведение фаз 4 и 5

Нужен Python 3.9+, внешние библиотеки не требуются.

```sh
python3 scripts/solve_phases45.py
python3 -m unittest discover -s scripts -p 'test_*.py' -v
```

Исходные данные — `phase-4/inputs.json` и `phase-5/inputs.json`. Скрипт формирует расчётные таблицы, показатели и диаграмму Ганта. Методика и выводы приведены в отчётах.
