# Информационная система автосервиса

Учебный проект по дисциплине «Проектный менеджмент».

## Команда
- Роде — участник 1
- Солопанов — участник 2
- Пухов — участник 3

## Концепция
Информационная система для автоматизации небольшого автосервиса: учёт клиентов и автомобилей, запись на обслуживание, заказы на ремонт, назначение механиков, учёт услуг и запчастей, контроль ремонта, расчёт стоимости.

## Структура
- `Задание.pdf` — исходное задание преподавателя.
- `phase-1/` … `phase-5/` — материалы и результаты соответствующих фаз.
- `shared/` — единые общекомандные учётные таблицы.
- `scripts/` — код расчётов, когда он появится.

## Расчётные материалы второй фазы
- `phase-2/Задачи_фазы_3.csv` — декомпозиция работ и оценка трудоёмкости.
- `phase-2/Предпочтения.csv` — индивидуальные оценки предпочтительности задач.
- `phase-2/Распределение_работ.xlsx` — оптимизация распределения задач между участниками.
- `phase-2/Распределение_демонстрация.csv` — результаты распределения работ.

## Расчётные материалы третьей фазы
- `phase-3/Use_Cases.csv` — пользовательские сценарии информационной системы.
- `phase-3/Расчёты_фазы_3.xlsx` — расчёты COSMIC Function Points и Use Case Points.
- `phase-3/Экспертные_оценки.csv` — экспертные оценки трудоёмкости пользовательских сценариев.
- `phase-3/metrics.json` — итоговые расчётные показатели проекта.
