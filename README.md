# Информационная система автосервиса

Учебный проект по дисциплине «Проектный менеджмент».

## Команда
- Роде — участник 1
- Солопанов — участник 2
- Пухов — участник 3

## Концепция
Информационная система для автоматизации небольшого автосервиса: учёт клиентов и автомобилей, запись на обслуживание, заказы на ремонт, назначение механиков, учёт услуг и запчастей, контроль ремонта, расчёт стоимости.

## Структура
- `Задание.pdf` — исходное задание преподавателя.
- `phase-1/` … `phase-5/` — материалы и результаты соответствующих фаз.
- `shared/` — единые общекомандные учётные таблицы.
- `scripts/` — код расчётов, когда он появится.

## Расчётные материалы первой фазы
- `phase-1/topsis.xlsx` — экспертные оценки, нормализация и рейтинг TOPSIS.
- `phase-1/mai.xlsx` — коллективная матрица критериев, локальные и глобальные приоритеты МАИ.
