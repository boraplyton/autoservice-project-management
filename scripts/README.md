# Расчётные скрипты

- `solve_phase2.py` — распределение работ фазы 3 по трудоёмкости и предпочтениям.
- `solve_phases45.py` — Монте-Карло, CPM, 12 эвристик, Serial SGS, 5 000 случайных порядков, проверка графиков, ресурсная нижняя граница, календарный план и диаграмма Ганта.
- `test_phases45.py` — 14 тестов, включая независимый полный перебор малого примера, календарные границы и сертификат оптимальности.

```sh
python3 scripts/solve_phases45.py
python3 scripts/solve_phases45.py --phase 4
python3 scripts/solve_phases45.py --phase 5
python3 -m unittest discover -s scripts -p 'test_*.py' -v
```

Для фаз 4–5 достаточно Python 3.9+ без внешних пакетов. Входы — `phase-4/inputs.json` и `phase-5/inputs.json`, выходы — таблицы и показатели в каталогах фаз. История `history` также формирует общий учёт времени. При изменении входов необходимо обновить связанные численные выводы отчётов.
