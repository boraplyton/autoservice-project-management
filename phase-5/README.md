# Фаза 5 — Планирование

[Отчёт](Отчёт%20—%20Фаза%205.md) · [Диаграмма Ганта](График.svg).

24 задачи реализации ИС, ресурсы DEV×2, QA×1, BA×1. Проверены 12 эвристик и 5 000 случайных порядков. **Оптимальная длительность — 317 рабочих часов**, трудоёмкость — **568 чел.-ч**. Оптимальность подтверждена ресурсной нижней границей.

План: **30.11.2026 09:00 — 22.01.2027 14:00**, график пн–пт 09:00–17:00, 40 часов в неделю.

| Файл | Содержание |
|---|---|
| `inputs.json` | Длительности, ресурсы, зависимости и параметры поиска |
| `Задачи_реализации.csv` | 24 задачи, трудоёмкость и связь с 12 UC |
| `CPM.csv` | Ранние/поздние сроки и резервы |
| `Сравнение_эвристик.csv` | 12 эвристик и лучший/худший случайные результаты из 5 000 порядков |
| `Календарный_план.csv` | Начала, завершения и исполнители |
| `Этапы.csv` | Сроки подготовки, разработки, проверки и выпуска |
| `metrics.json` | Итоги и сертификат оптимальности |

Запуск из корня: `python3 scripts/solve_phases45.py --phase 5`.
