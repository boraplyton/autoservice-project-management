# Фаза 5 — Планирование

- Разбить реализацию ИС автосервиса на ~20–25 задач.
- Определить специальности и состав команды на основе фазы 3.
- Задать для задач длительность, ресурсные требования и предшествование.
- Решить задачу планирования несколькими эвристиками и случайными порядками приоритетов; выбрать лучшее найденное решение.
- Пересчитать график в рабочие дни (8 часов в день, 40 часов в неделю), определить сроки проекта и этапов.
