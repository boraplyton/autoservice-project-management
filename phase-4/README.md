# Фаза 4 — Прогнозирование

[Отчёт](Отчёт%20—%20Фаза%204.md).

Две модели Монте-Карло прогнозируют выполнение 12 учебных работ фазы 5. На каждой модели выполнено 100 000 прогонов. P80: **10 недель по числу задач, 13 недель по человеко-часам**.

| Файл | Содержание |
|---|---|
| `inputs.json` | История, трёхточечные оценки, параметры моделирования |
| `Задачи_фазы_5.csv` | 12 работ, ответственные, оценки и зависимости |
| `Недельная_статистика.csv` | Все полные прошедшие недели |
| `metrics.json` | P50, P80, P90, средние сроки и чувствительность |

Запуск из корня: `python3 scripts/solve_phases45.py --phase 4`.
