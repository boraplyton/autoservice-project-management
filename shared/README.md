# Общий учёт проекта

- `RACI.csv` — единая матрица ответственности всех фаз: R выполняет, A отвечает за результат, C консультирует, I информируется.
- `Учёт_времени.csv` — часы и периоды учебных работ с указанием источника.
- `Issues_фаз_4_5.md` — задачи фаз 4–5, ответственные и GitHub Issues.

Команда: Роде, Солопанов, Пухов. Распределение фиксируется по фамилиям в общей RACI.

Пользователь подтвердил, что оценки соответствуют фактическому времени. Для фазы 3 учтены 45 чел.-ч из декомпозиции, для фазы 5 — 30 чел.-ч наиболее вероятных оценок. Для фазы 4 пользователь отдельно подтвердил суммарные 30 чел.-ч; они приближённо распределены по семи работам как 3/5/5/6/4/3/4 ч. Периоды работ привязаны к датам публикации результатов: 24 ноября для фазы 3 и 25 ноября для фаз 4–5. Это основание дат указано в каждой записи. Общие встречи фазы 1 считаются как длительность × 3 участника; итоговые 22 ч фазы 2 используются как суммарные человеко-часы.

Калибровка прогноза использует все полные недели с 28.09 по 22.11.2026. Записи текущей недели сохраняются в общем учёте, но не участвуют в калибровке до её завершения.
