# Фаза 3 — Оценка проекта

Для концепции ИС автосервиса:
- Подготовить **10–15 Use Cases**, включая альтернативные и негативные сценарии.
- Оценить COSMIC Function Points.
- Оценить Use Case Points и на их основе трудозатраты.
- Провести коллективное экспертное оценивание Use Cases с согласованной итоговой оценкой.
- Сопоставить методы, определить ориентировочные команду, сроки, функциональность для возможного исключения.

Результаты сохранять здесь. Исполнители определяются в фазе 2.
